One word, one username, one reward: this entry sends our own make.fun username, **oldfx**, and nothing else — exactly what the bounty asks. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting; oldfx is short, punchy, and carries a veteran story in five characters ("old" + "fx").

## Run it

```sh
node main.ts
```

It writes the username to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
